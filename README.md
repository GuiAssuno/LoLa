### Como a arquitetura funciona agora:

1. **A Interface Gráfica:** Você usará a biblioteca **PyQt6** **CustomTkinter** .

2. **A Comunicação:** Você usará a biblioteca padrão **PySerial**.

3. **A Comunicação:** Você usará a biblioteca **Bleak** (para Bluetooth Low Energy, ideal para ESP32).
